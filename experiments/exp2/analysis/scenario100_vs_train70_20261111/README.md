# Сценарный 100 vs сценарный 70: Jev / Luna

Полная выборка — **193**, train — **135**, test — **58**; во всех решениях 17 кандидатов. 2-step использует shortlist=5. Проценты без порогов confidence. Ошибки API входят в знаменатель и считаются промахами. Срез test извлечён по original_sample_id из тех же ответов, повторного инференса не было.

- **Сценарный 100**: `exp2/prompts/routing_scenarios_ru_exp2.txt`, разработан по всем 193; test здесь ретроспективный срез уже использованных примеров, а не независимый holdout.
- **Сценарный 70**: `exp2/prompts/routing_train70_ru_exp2.txt`, отдельный изолированный автор получил 135 train+статический каталог; промпт зафиксирован до этих прогонов.

## Что изменилось

| Модель | Стратегия | ΔFull @1 (70−100), п.п. | ΔTest @1, п.п. | Train @1 у70 | Test @1 у70 |
| --- | --- | ---: | ---: | ---: | ---: |
| Jev 1.14 | 1-step | -0.52 | -17.24 | 98.52% | 81.03% |
| Jev 1.14 | 2-step | +1.04 | -12.07 | 97.78% | 87.93% |
| Luna | 1-step | -4.66 | -17.24 | 94.07% | 81.03% |
| Luna | 2-step | -2.59 | -13.79 | 94.81% | 84.48% |

На full новый Jev2-step даже растёт на 2 правильных ответа, но на test уступает на 7. Поэтому full скрывает различие настройки на train и переноса на отложенную часть. У нового промпта разрыв train−test составляет 9.85–17.48п.п. по этим четырём стратегиям.

У всех новых test-результатов @3=@5=100%. Правильный агент сохраняется в shortlist, ошибки относятся к ранжированию первого места; 2-step поднимает Jev с 47 до 51 правильного ответа, Luna — с 47 до 49.

Старый промпт имеет 98.28–100% на этих 58, но видел их при разработке. Разница не является чистой оценкой эффекта объёма train: кроме доступа к данным различаются автор/формулировки/длина промпта и время API-прогона. Новый test полезнее для оценки переноса этого промпта, но один вопрос даёт 1.72п.п., редкие классы представлены единичными примерами, семантические перефразировки не группировались.
